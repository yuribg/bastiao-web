PROTEGER UMA ROTA:
──────────────────
import { authGuard } from './core/auth/auth.guard';

export const routes: Routes = [
  { path: '', component: HomeComponent },
  { 
    path: 'dashboard',
    component: DashboardComponent,
    canActivate: [authGuard]  // ← Protegida!
  }
];

USAR AUTHSERVICE EM COMPONENTE:
───────────────────────────────
import { AuthService } from './core/auth/auth.service';

export class MyComponent {
  private authService = inject(AuthService);

  // Verificar autenticação
  isLoggedIn = this.authService.isLoggedIn();

  // Obter dados do usuário
  profile = this.authService.getUserProfile();

  // Fazer logout
  logout() {
    this.authService.logout();
  }
}

🔒 SEGURANÇA - O QUE ESTÁ PROTEGIDO
═════════════════════════════════════════════════════════════════════════════

✅ PKCE (Proof Key for Public Clients)
   └─ Protege contra ataques de autorização em SPAs
   └─ Code verifier gerado para cada login
   └─ Code challenge enviado ao provedor

✅ SEM CLIENT SECRET
   └─ Seguro para aplicações no browser
   └─ Não expõe credenciais

✅ TOKEN EM REQUISIÇÕES HTTP
   └─ Header: Authorization: Bearer <token>
   └─ Adicionado automaticamente pelo interceptor

✅ REFRESH AUTOMÁTICO
   └─ Tokens renovados em background
   └─ Sessão mantida ativa
   └─ Sem interrupção para o usuário

✅ LOGOUT COMPLETO
   └─ Tokens removidos do armazenamento
   └─ Sessão encerrada

📊 FLUXO COMPLETO DE LOGIN
═════════════════════════════════════════════════════════════════════════════

USUÁRIO CLICA "ENTRAR"
         ↓
   PKCE GERADO
   (code_verifier + code_challenge)
         ↓
REDIRECIONADO PARA PROVEDOR OIDC
         ↓
USUÁRIO FAZ LOGIN (email/senha, MFA, etc)
         ↓
PROVEDOR REDIRECIONA COM CODE
         ↓
APP TROCA CODE POR TOKENS
   (sem client_secret - seguro!)
         ↓
TOKENS ARMAZENADOS
   (access_token, id_token, refresh_token)
         ↓
✅ USUÁRIO AUTENTICADO
   • Acesso a rotas protegidas
   • Token em todas requisições HTTP
   • Refresh automático mantém sessão

🆘 HELP RÁPIDO
═════════════════════════════════════════════════════════════════════════════

ERRO: "Invalid issuer"
SOLUÇÃO: Remova trailing slash (use: https://provider.com, não https://provider.com/)

ERRO: CORS error
SOLUÇÃO: Configure CORS no provedor OIDC para aceitar seu domínio

ERRO: Tokens não aparecem
SOLUÇÃO: Abra DevTools (F12) → Application → Session Storage
        Procure por "oidc" - se vazio, login não funcionou

ERRO: AuthGuard não redireciona
SOLUÇÃO: Verifique se está importado em app.routes.ts

MAIS HELP: Veja OIDC_SETUP_GUIDE.md (seção Troubleshooting)
