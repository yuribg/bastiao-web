🎯 FUNCIONALIDADES PRINCIPAIS

AuthService (Serviço Principal)
├─ login() ...................... Iniciar fluxo de login
├─ logout() ..................... Fazer logout
├─ isLoggedIn() ................. Verificar autenticação
├─ getUserProfile() ............. Obter dados do usuário
├─ getAccessToken() ............. Token para APIs
├─ getIdToken() ................. Token de identidade
├─ refreshToken() ............... Renovar token
└─ getIsLoggedIn$() ............. Observable de status

AuthGuard (Proteção de Rotas)
├─ authGuard .................... Guard funcional
│  Uso: canActivate: [authGuard]
└─ AuthGuardService ............. Guard em classe

AuthInterceptor (Inclusão Automática de Token)
├─ Adiciona automaticamente header:
│  Authorization: Bearer <token>
└─ Funciona em todas requisições HTTP

UserProfileComponent (UI)
├─ Botão de login/logout
├─ Exibição de perfil
├─ Observable de autenticação
└─ Styling pronto

🚀 FLUXO DE LOGIN COMPLETO

1. USUÁRIO CLICA "ENTRAR"
   ↓
2. authService.login() iniciado
   ↓
3. PKCE gerado automaticamente
   ├─ code_verifier (256 caracteres aleatórios)
   └─ code_challenge (hash do verifier)
   ↓
4. REDIRECT PARA PROVEDOR OIDC
   URL: https://seu-provedor.com/authorize?
        client_id=...&code_challenge=...&...
   ↓
5. USUÁRIO FAZ LOGIN NO PROVEDOR
   (email/senha, MFA, OAuth social, etc)
   ↓
6. PROVEDOR REDIRECIONA DE VOLTA
   URL: http://localhost:4200?code=...&state=...
   ↓
7. APP TROCA CÓDIGO POR TOKENS
   POST https://seu-provedor.com/token
   ├─ code=...
   ├─ code_verifier=...
   └─ client_id=...
   ↓
8. TOKENS RECEBIDOS
   ├─ access_token (para APIs)
   ├─ id_token (perfil do usuário)
   └─ refresh_token (renovação)
   ↓
9. TOKENS ARMAZENADOS
   └─ sessionStorage (seguro)
   ↓
10. USUÁRIO AUTENTICADO ✅
    ├─ Acesso a rotas protegidas
    ├─ Token em todas requisições HTTP
    └─ Refresh automático mantém sessão

📞 TROUBLESHOOTING RÁPIDO

Problema: Login não funciona
Solução: 
  1. Verificar console (F12)
  2. Confirmar issuer em environment.ts
  3. Confirmar clientId em environment.ts
  4. Testar acesso ao provedor OIDC

Problema: CORS error
Solução:
  1. Configurar CORS no provedor OIDC
  2. Adicionar seu domínio na lista allowed origins
  3. Reiniciar aplicação

Problema: Token não aparece
Solução:
  1. DevTools → Application → Session Storage
  2. Procurar por "oidc" ou "token"
  3. Se vazio, login não funcionou
  4. Ver console para erros

Mais troubleshooting em:
→ OIDC_SETUP_GUIDE.md (seção Troubleshooting)
