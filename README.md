# Plataforma de Bastiões

## Apresentação

A plataforma de Bastiões é um espaço interno para acompanhar os textos mensais e consultar conteúdos de apoio à formação filosófica.

## Como acessar

O acesso é feito pelo login Acrópole, utilizando o mesmo acesso usado, por exemplo, na plataforma de eventos. Não é necessário criar um novo cadastro.

## O que você encontra na plataforma

A plataforma está organizada em três abas:

- **Bastiões do mês:** reúne os textos mais recentes, com atualização ao longo do ano.
- **Bastiões de anos anteriores:** disponibiliza o acervo de outros anos. Esses textos ainda passarão por revisão.
- **Livros:** reúne livros em domínio público para consulta e aprofundamento dos estudos.

Use as abas para navegar pelo acervo e acesse cada texto ou livro pelos botões disponíveis na página.
